Використання засобів ШІ (Лабораторна робота 1):
- за допомогою ШІ було згенеровано варіанти тематики додатку, з яких обрано "Курс основ JavaScript", а також підібрано відповідні іконки для елементів навігації;

- здійснено детальний розбір параметрів вирівнювання, зокрема принципів роботи horizontalAlignment у Column та Modifier.align у Box, що дозволило коректно скомпонувати два різні екрани;

- проведено аналіз життєвого циклу Android із покроковим розбором внутрішньої механіки та різниці між делегатом remember, rememberSaveable та компонентом ViewModel;

- ШІ був використаний у процесі дебагінгу для вирішення помилок середовища, що дозволило визначити відсутні імпорти, які необхідно було додати до файлу.
